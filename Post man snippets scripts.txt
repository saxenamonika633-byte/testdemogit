1. Status code: Code is 200
Use >
 Check karta hai ki API ne 200 OK response diya ya nahi.

Example
Agar Login API successful hai to status code 200 aana chahiye.

pm.test("Status code is 200", function () {
    pm.response.to.have.status(200);
});

Status : 200  ✅ Test Pass
Agar

3. Response body: JSON value check
Use

JSON ke kisi field ki value check karta hai.

Example Response

    "lastname":"Smith",
    "bookingid":120

pm.test("Check First Name", function () {
